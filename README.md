# Дипломная работа: Автоматизация тестирования сервиса YouGile

Репозиторий содержит автоматизированные тесты для веб-интерфейса и API таск-менеджера YouGile, созданные в рамках выполнения дипломной работы.

## Область покрытия автотестов:

*   **UI-автоматизация:** Проверка сквозных сценариев пользователя в трех ключевых модулях системы (управление проектами, работа с задачами на Agile-досках, а также коммуникация и обмен сообщениями внутри сервиса).
*   **API-автоматизация:** Проверка серверной части для модулей «Проекты», «Задачи» и «Чаты». Тесты автоматически отправляют запросы методами POST, GET, PUT и PATCH, проверяя как успешные сценарии, так и обработку ошибок сервером:
    *   *Позитивные сценарии:* создание задач и чатов, отправка сообщений, получение списков данных и удаление существующих проектов.
    *   *Негативные сценарии:* проверка реакции сервера на превышение лимита в запросе, отправку пустых значений параметров и использование неподдерживаемых методов (PATCH).
