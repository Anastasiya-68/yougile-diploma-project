# Дипломная работа: Автоматизация тестирования сервиса YouGile

Репозиторий содержит автоматизированные UI- и API-тесты для веб-приложения и REST API таск-менеджера **YouGile**, разработанные в рамках дипломного проекта по профессии «Инженер по тестированию».

## Документация и результаты тестирования

Полное описание дипломного проекта (тест-план, тест-кейсы, чек-листы, отчеты о дефектах, коллекция Postman и видеозащита) доступно на странице в Yonote:
* **[Открыть проект в Yonote](<https://frolova-anastasiya.yonote.ru/share/4419063c-503b-48b1-a656-8942c5592680>)**

## Стек технологий

* **Язык программирования:** Python 3.14
* **Фреймворк тестирования:** Pytest
* **UI-автоматизация:** Selenium WebDriver (паттерн Page Object Model)
* **API-автоматизация:** Requests (REST API YouGile v2.0)
* **Генерация тестовых данных:** Faker
* **Отчетность:** Allure Framework

## Покрытие автотестами

Проект включает **10 независимых сценариев** (5 UI-тестов и 5 API-тестов):

### UI-тесты (`test/test_ui.py`)
1. Создание нового проекта с задачами через кнопку «+ Добавить проект».
2. Изменение названия существующего проекта через верхнюю панель управления.
3. Удаление существующей задачи из колонки проекта.
4. Изменение названия группового чата проекта в разделе «Мессенджер».
5. Отправка текстового сообщения в чат существующего проекта.

### API-тесты (`test/test_api.py`)
1. Получение информации о проекте по его ID (`GET /projects/{id}`).
2. Создание новой задачи в колонке проекта (`POST /tasks`).
3. Получение списка задач (`GET /task-list`).
4. Создание нового группового чата (`POST /group-chats`).
5. Отправка текстового сообщения в чат с использованием параметризации (`POST /chats/{id}/messages`).

## Установка и настройка

1. **Клонируйте репозиторий и перейдите в папку проекта:**
   ```bash
   git clone <ссылка-на-ваш-репозиторий>
   cd yougile-diploma-project
   ```

2. **Создайте и активируйте виртуальное окружение:**
   ```bash
   python -m venv .venv
   # Для Windows:
   .venv\Scripts\activate
   # Для macOS/Linux:
   source .venv/bin/activate
   ```

3. **Установите зависимости:**
   ```bash
   pip install -r requirements.txt
   ```

4. **Создайте файл конфигурации и заполните учетные данные:**
   Скопируйте шаблон `config.example.py` в файл `config.py`:
   ```bash
   # Для Windows:
   copy config.example.py config.py
   # Для macOS/Linux:
   cp config.example.py config.py
   ```
   Откройте созданный `config.py` и впишите актуальные данные вашей тестовой учетной записи и ключ API YouGile.

## Запуск тестов и формирование отчетов

Настройки в `pytest.ini` автоматически сохраняют результаты прогона в папку `allure-results`.

* **Запуск всех тестов (UI + API):**
  ```bash
  pytest
  ```

* **Запуск только UI-тестов:**
  ```bash
  pytest test/test_ui.py
  ```

* **Запуск только API-тестов:**
  ```bash
  pytest test/test_api.py
  ```

* **Просмотр отчета Allure в браузере:**
  ```bash
  allure serve allure-results
  ```
